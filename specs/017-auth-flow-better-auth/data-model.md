## Table Definitions

### 1. user (Better-Auth Core)

Stores authenticated user identity from OAuth providers.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| id | VARCHAR(36) | PK | UUID generated by Better-Auth |
| email | VARCHAR(255) | UNIQUE, NOT NULL | User's email from OAuth |
| name | VARCHAR(255) | | Display name from OAuth |
| emailVerified | BOOLEAN | DEFAULT false | Email verification status |
| image | VARCHAR(500) | | Avatar URL from OAuth |
| createdAt | TIMESTAMP | NOT NULL | Account creation time |
| updatedAt | TIMESTAMP | NOT NULL | Last update time |

**Indexes**:
- `idx_user_email` on `email`

---

### 2. session (Better-Auth Core)

Stores active authentication sessions.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| id | VARCHAR(36) | PK | Session UUID |
| userId | VARCHAR(36) | FK → user.id | Session owner |
| token | VARCHAR(255) | UNIQUE, NOT NULL | Session token (in cookie) |
| expiresAt | TIMESTAMP | NOT NULL | Session expiration (7 days) |
| ipAddress | VARCHAR(45) | | Client IP for security |
| userAgent | VARCHAR(500) | | Browser/device info |
| createdAt | TIMESTAMP | NOT NULL | Session creation time |
| updatedAt | TIMESTAMP | NOT NULL | Last activity time |

**Indexes**:
- `idx_session_token` on `token`
- `idx_session_userId` on `userId`
- `idx_session_expiresAt` on `expiresAt`

---

### 3. account (Better-Auth Core)

Links users to OAuth provider accounts.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| id | VARCHAR(36) | PK | Account link UUID |
| userId | VARCHAR(36) | FK → user.id | Linked user |
| accountId | VARCHAR(255) | NOT NULL | Provider's user ID |
| provider | VARCHAR(50) | NOT NULL | "github" or "google" |
| accessToken | TEXT | | OAuth access token |
| refreshToken | TEXT | | OAuth refresh token |
| accessTokenExpiresAt | TIMESTAMP | | Token expiration |
| refreshTokenExpiresAt | TIMESTAMP | | Refresh token expiration |
| scope | VARCHAR(500) | | Granted OAuth scopes |
| idToken | TEXT | | OIDC ID token |
| createdAt | TIMESTAMP | NOT NULL | Link creation time |
| updatedAt | TIMESTAMP | NOT NULL | Last update time |

**Indexes**:
- `idx_account_userId` on `userId`
- `idx_account_provider` on `(provider, accountId)` UNIQUE

---

### 4. verification (Better-Auth Core)

Stores temporary verification tokens (email verify, password reset).

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| id | VARCHAR(36) | PK | Verification UUID |
| identifier | VARCHAR(255) | NOT NULL | Email or identifier |
| value | VARCHAR(255) | NOT NULL | Verification token |
| expiresAt | TIMESTAMP | NOT NULL | Token expiration |
| createdAt | TIMESTAMP | NOT NULL | Creation time |

**Indexes**:
- `idx_verification_identifier` on `identifier`
- `idx_verification_value` on `value`

---

### 5. user_profile (PhysAI Extension)

Stores survey responses and user preferences.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| id | VARCHAR(36) | PK | Profile UUID |
| userId | VARCHAR(36) | FK → user.id, UNIQUE | One profile per user |
| role | VARCHAR(50) | | student, researcher, hobbyist, professional |
| softwareBackground | JSONB | DEFAULT '[]' | Array of skills |
| hardwareAccess | JSONB | DEFAULT '[]' | Array of hardware |
| learningGoal | VARCHAR(100) | | Primary learning objective |
| surveyCompleted | BOOLEAN | DEFAULT false | Survey completion flag |
| surveyCompletedAt | TIMESTAMP | | When survey was completed |
| createdAt | TIMESTAMP | NOT NULL | Profile creation time |
| updatedAt | TIMESTAMP | NOT NULL | Last update time |

**Indexes**:
- `idx_profile_userId` on `userId` UNIQUE
- `idx_profile_surveyCompleted` on `surveyCompleted`

## Validation Rules

### user
- `email`: Valid email format, max 255 chars
- `name`: Max 255 chars, allows unicode

### session
- `expiresAt`: Must be in future, max 7 days from creation
- `token`: Cryptographically random, 64+ chars

### account
- `provider`: Must be "github" or "google"
- `accessToken`: Encrypted at rest

### user_profile
- `role`: Must be one of: student, researcher, hobbyist, professional
- `softwareBackground`: Array of valid skill codes
- `hardwareAccess`: Array of valid hardware codes
- `learningGoal`: Must be one of: build_humanoid, understand_embodied_ai, career_transition, academic_research

## State Transitions

### User Lifecycle

```
Anonymous → OAuth Initiated → OAuth Completed → Survey Pending → Survey Completed
                                    ↓
                              user created
                              account linked
                              session created
                              profile created (surveyCompleted=false)
                                    ↓
                              user completes survey
                              profile updated (surveyCompleted=true)
```

### Session Lifecycle

```
Created → Active → Expired/Revoked
   ↓        ↓           ↓
7 days   refresh    delete from DB
         extends
```

## Migration Script

```sql
-- Migration: 001_create_auth_tables.sql

-- Better-Auth core tables
CREATE TABLE "user" (
    id VARCHAR(36) PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    name VARCHAR(255),
    "emailVerified" BOOLEAN DEFAULT false,
    image VARCHAR(500),
    "createdAt" TIMESTAMP NOT NULL DEFAULT NOW(),
    "updatedAt" TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE TABLE session (
    id VARCHAR(36) PRIMARY KEY,
    "userId" VARCHAR(36) NOT NULL REFERENCES "user"(id) ON DELETE CASCADE,
    token VARCHAR(255) UNIQUE NOT NULL,
    "expiresAt" TIMESTAMP NOT NULL,
    "ipAddress" VARCHAR(45),
    "userAgent" VARCHAR(500),
    "createdAt" TIMESTAMP NOT NULL DEFAULT NOW(),
    "updatedAt" TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE TABLE account (
    id VARCHAR(36) PRIMARY KEY,
    "userId" VARCHAR(36) NOT NULL REFERENCES "user"(id) ON DELETE CASCADE,
    "accountId" VARCHAR(255) NOT NULL,
    provider VARCHAR(50) NOT NULL,
    "accessToken" TEXT,
    "refreshToken" TEXT,
    "accessTokenExpiresAt" TIMESTAMP,
    "refreshTokenExpiresAt" TIMESTAMP,
    scope VARCHAR(500),
    "idToken" TEXT,
    "createdAt" TIMESTAMP NOT NULL DEFAULT NOW(),
    "updatedAt" TIMESTAMP NOT NULL DEFAULT NOW(),
    UNIQUE(provider, "accountId")
);

CREATE TABLE verification (
    id VARCHAR(36) PRIMARY KEY,
    identifier VARCHAR(255) NOT NULL,
    value VARCHAR(255) NOT NULL,
    "expiresAt" TIMESTAMP NOT NULL,
    "createdAt" TIMESTAMP NOT NULL DEFAULT NOW()
);

-- PhysAI extension: user profile with survey data
CREATE TABLE user_profile (
    id VARCHAR(36) PRIMARY KEY,
    "userId" VARCHAR(36) UNIQUE NOT NULL REFERENCES "user"(id) ON DELETE CASCADE,
    role VARCHAR(50),
    "softwareBackground" JSONB DEFAULT '[]',
    "hardwareAccess" JSONB DEFAULT '[]',
    "learningGoal" VARCHAR(100),
    "surveyCompleted" BOOLEAN DEFAULT false,
    "surveyCompletedAt" TIMESTAMP,
    "createdAt" TIMESTAMP NOT NULL DEFAULT NOW(),
    "updatedAt" TIMESTAMP NOT NULL DEFAULT NOW()
);

-- Indexes
CREATE INDEX idx_user_email ON "user"(email);
CREATE INDEX idx_session_token ON session(token);
CREATE INDEX idx_session_userId ON session("userId");
CREATE INDEX idx_session_expiresAt ON session("expiresAt");
CREATE INDEX idx_account_userId ON account("userId");
CREATE INDEX idx_account_provider ON account(provider, "accountId");
CREATE INDEX idx_verification_identifier ON verification(identifier);
CREATE INDEX idx_verification_value ON verification(value);
CREATE INDEX idx_profile_userId ON user_profile("userId");
CREATE INDEX idx_profile_surveyCompleted ON user_profile("surveyCompleted");
```
